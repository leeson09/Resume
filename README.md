# Leeson Glen Dsouza — Resume

A single-page, responsive HTML/CSS resume hosted on GitHub Pages.

## Files
- `index.html` — the full resume page (self-contained, no build step)
- `.nojekyll` — tells GitHub Pages to serve files as-is

## View locally
Just open `index.html` in any web browser.

## Live site
After enabling GitHub Pages (see below): `https://<your-username>.github.io/resume/`

## How to update
Edit `index.html`, then commit and push. GitHub Pages redeploys automatically.
